# 论文专属约束（本地化层）

本文件是 thesis-polish 的**最高优先级约束**，凌驾于通用 patterns 之上。
与通用规则冲突时，以本文件为准。

**这是一个模板。** 第一次用于你自己的论文时，把每一节里的 `<...>` 占位符换成
真实值。填完这一份，skill 的通用规则层就从「中文毕业论文通用」收紧到
「你这篇论文专用」，审校精度差别很大。

第四节和第六节的示例块（标注 `<!-- 示例 -->`）是给写法做参照的，填自己的
内容时整块替换掉，不要留着。

## 二、术语硬约束（违反即改）

测绘与 GNSS 领域有惯用词。**一致性优先于正确性**——即使两种写法都对，
全文也只能用一种。

填这一节的方法：把全文搜一遍，凡是你打算统一成某一种写法的词，记进左列。
右列是必须写成的那一种。

### 2.1 禁用写法（出现即替换）

以下是测绘/GNSS 方向的常用条目，按你自己的论文取舍：

| 禁用 | 必须写成 | 理由 |
|---|---|---|
| 紧耦合 | **紧组合** | GNSS 领域惯用「组合」 |
| 鲁棒、稳健 | **抗差** | 测绘领域惯用「抗差」 |
| 均方根信息滤波 | **平方根信息滤波** | SRIF 标准译名 |
| 力学编排、捷联解算 | **机械编排** | INS mechanization 标准译名 |
| 杠杆臂 | **杆臂** | lever arm 标准译名 |
| 摄像机、摄像头 | **相机** | 全文统一 |
| 视觉惯导里程计 | **视觉惯性里程计** | VIO 标准译名 |
| 预先积分 | **预积分** | |
| 拒止、denied | **<你选定的说法>** | 见第三节 |

### 2.2 缩写与大小写（全文严格一致）

把本领域缩写列全，写清大小写与连字符。例如：

- `GNSS`（不写 gnss、Gnss）
- `INS`、`IMU`、`VIO`、`EKF`、`MSCKF`、`SRIF`
- `PPP-RTK`、`UC-PPP`（中间连字符）
- `LiDAR`（不写 LIDAR、lidar）
- `LAMBDA`（全大写）
- `ECEF`、`ENU`、`NED`、`RMS`、`CEP`、`RMSE`（全大写）

### 2.3 区分易混概念

- **IMU** 是传感器，**INS** 是系统。「IMU 预积分」对；不要把两者混用。
- **因子图**是图结构，**因子图优化**是求解过程。
- 精度指标统一用 `RMS`，或统一用 `CEP`；用 `CEP` 必须在首现处定义。

### 2.4 首次出现规则

术语首现给「中文全称（英文全称，缩写）」，之后用缩写。
摘要中**不堆缩写**——摘要要能独立阅读。

## 三、题目口径约束

题目是选题阶段反复迭代收敛的结果。写作时若发现正文偏离了题目口径，
要么改正文，要么回头改题目，**不要两处说法不同**。

这一节要写的不是「题目是什么」，而是「题目敲定了哪些不能再动的边界」。

## 五、LaTeX 保护规则

审校 `.tex` 文件时，**除中文正文外一律不动**。

### 5.1 绝对不动

- `\cite{}`、`\ref{}`、`\eqref{}`、`\label{}`、`\autoref{}` 的内容
- `\begin{...}` … `\end{...}` 环境结构
- 公式内部（`$...$`、`\[...\]`、`equation`/`align` 等环境）的符号与排版
- 模板配置块（如 `\whusetup{...}`）
- 表格、图片的 `tabular` / `includegraphics` 参数
- 注释掉的行（`%` 开头）

### 5.2 禁止新增

- **不要手动调版式**：`\zihao{}`、`\fontsize{}`、`\vspace{}`、`\linespread{}`
  一律不加。模板已按学校规范设定，硬调会在模板更新时失效。
- **不要手写图表编号**：正文里的「图 3-2」「式（3-5）」必须来自 `\ref{}`，
  手写编号插入新图表后会全部错位。

### 5.3 裸 `%` 是硬错误

LaTeX 中 `%` 是注释符。写 `覆盖率95%。` 会**静默吞掉整行剩余内容**，
编译不报错，文字凭空消失。百分号必须写 `\%`。

审校时见到 `数字%` 或 `汉字%` 立即报必改。

### 5.4 学校格式（模板已自动处理，不必干预）

把你所用模板已经处理的格式项记在这里，避免审校时重复干预。
查 `whu-thesis.cls` 一类模板源文件即可确认。常见的有正文号数、行距、
页边距、各级标题字号、参考文献样式。

**模板管不了、必须人工查的**：图表是否都在正文被引用、参考文献正文与文末
是否一一对应、摘要中是否出现了交叉引用或文献引用。

## 六、章节地图与逐章约束

把各章的功能、来源成果、审校要点列成表，审某一章时只加载对应行。

| 章 | 标题 | 功能 | 来源成果 | 审校要点 |
|---|---|---|---|---|
| 1 | `<标题>` | 背景、现状、问题、内容 | — | `<要点>` |
| 2 | | 符号体系与模型基础 | — | |
| … | | | | |

**写这一节最容易漏的一条**：方法章要说明与已发表论文的关系；应用章
**不得引入未在方法章验证过的新方法**，真值来源与局限必须正面写；
结论章创新点要与绪论的「存在的问题」一一对应，不足写真话。

## 八、约束优先级

遇到规则冲突时，按此顺序判定：

1. 本节所有硬约束（术语、口径、LaTeX 保护）
2. `meta-rules.md` 的 K1–K8
3. 两个核心自检问题（删除测试 + 范例测试）
4. `patterns-*.md` 的具体黑名单

**范例测试的例外**：范例论文若用了本文禁用词（如「鲁棒」），
**以本文件的术语约束为准**，不跟着范例走。
